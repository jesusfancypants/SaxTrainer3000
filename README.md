# Saxophonator 3000  

---

### What’s this monstrosity?  
A mélange of dubious ingenuity and questionable charm. Two gloriously absurd modes await your judgment:  

- **Manual Mode**: Tap the spacebar to switch notes. Pourquoi spacebar? Because life is mysterious, mon ami.  
- **Timer Mode**: Notes change randomly within your chosen octaves, dictated by some rogue dice-rolling algorithm that revels in chaos.  

---

### What’s included?  

Behold, the *pièce de résistance*:  

- A painstakingly hand-drawn **alto saxophone fingering chart**, created with the artistic flair of a caffeinated squirrel.  
- Backing tracks from Barcelona Universitat Pompeu Fabra – because nothing says “sophistication” like free academic loops.  
- A **metronome click** that is either fascinating or an existential crisis in audio form.  
- Two sliders for BPM and delay between notes. Warning: if you crank these to the extremes, you’ll summon a musical demon. Bonne chance!  
- Four octaves to choose from (not full, because saxophones have *attitude*).  
- **SHARPS!** Because why not? Also **ENHARMONICS**, because music theory needed a spice rack.  
- Alternative fingerings – your sax, your rules.  
- **Stealth Mode for Note Names**: Now you can learn by ear *like a shadowy sax ninja*. Bonus: dimmed labels for that sweet squinting challenge.  

---

### Customization à la chaos  

- Tweak `notes.json` to include/exclude notes or expand into forbidden octaves. Feeling adventurous? Code in another instrument – the saxophonator won’t stop you (but it might laugh).  
- Replace files in `resources.json` with your own bizarre imagery or sounds. Voilà – personalized madness!  

---

### Known catastrophes  

- The highest notes might be missing fingering charts or sounds. Or dignity. Hard to say.  
- The code is... let’s call it “art brut.” Definitely not a Michelangelo.  

### Unknown catastrophes  

- Enabling the wrong combination of options could result in musical mayhem. But isn’t that part of the fun?  
- Untested on Windows, so its behavior is *mystère extraordinaire*.  

---

### How to Install  

1. Clone the repository:  

   ```bash
   git clone https://github.com/jesusfancypants/SaxTrainer3000.git
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
   
3. Run the program:
   ```bash
   python main.py
   ```
